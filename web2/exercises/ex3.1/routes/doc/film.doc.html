URI HTTP Method Auth Operation
/films GET No READ ALL: Lire toutes les ressources de la collection, avec filtres minDuration et starts-with
/films/:id GET No READ ONE: Lire une ressource spécifique
/films POST Yes (Admin) CREATE ONE: Créer un film avec body {title, director, duration, budget?, description?, imageUrl?}
/films/:id PUT Yes (Admin) REPLACE ONE: Remplacer un film existant
/films/:id PATCH Yes (Admin) UPDATE ONE: Mettre à jour partiellement un film
/films/:id DELETE Yes (Admin) DELETE ONE: Supprimer un film
/comments GET Yes (JWT) READ ALL FILTERED: Lire tous les commentaires
/comments POST Yes (JWT) CREATE ONE: Ajouter un commentaire {filmId, username, content}
/comments/:filmId/:username DELETE Yes (JWT) DELETE ONE: Supprimer un commentaire spécifique
